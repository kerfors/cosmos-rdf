# /cdisc/cosmos/
#
# https://w3id.org/cdisc/cosmos/ is the namespace for an RDF/OWL rendering
# of CDISC COSMoS (Biomedical Concepts and SDTM Dataset Specializations),
# generated mechanically from the artifacts published in cdisc-org/COSMoS,
# plus an authored overlay of qualified biomedical concepts. Slash
# semantics. The namespace names the ontologies, their instance graphs and
# their releases, and the IRIs the repository mints under them; the class
# and property IRIs of the core rendering stay as CDISC published them
# (https://www.cdisc.org/cosmos/...) and are not served here.
#
# Segments:
#   bc/            core BC ontology          cosmos_bc_v1
#   bc/instances/  core BC instance graph    cosmos_bc_v1.instances
#   sdtm/          core SDTM ontology        cosmos_sdtm_v1
#   qbc/           overlay ontology          cosmos_qbc_v1
#   qbc/instances/ overlay instance graph    cosmos_qbc_v1.instances
#   dss/           RESERVED, not registered: the Dataset Specialization
#                  instance graph is deferred (cosmos-rdf decision D4). The
#                  IRIs already minted under it (recording subjects) are
#                  stable identity and will resolve when that layer lands;
#                  until then they 404 by design.
#
# Rule: an IRI resolves to a document that has it as subject. A term of
# the overlay ontology (class, property; enum values carry a fragment, so
# the enum is the term) resolves to the ontology; an individual - a
# qualified concept, a scale node, a use-node, a category label-node - to
# its instance graph; an ontology IRI to the ontology at the pinned
# release; a version IRI (bare-numeric path, e.g. bc/0.3.0) to its own
# release through one generic rule per graph. Fixed paths serve the
# JSON-LD contexts (bc/context.jsonld, sdtm/context.jsonld) and the SHACL
# shapes (bc/shapes, sdtm/shapes, qbc/shapes).
#
# Targets are the GitHub Pages site of kerfors/cosmos-rdf, rebuilt from
# every release tag: /vX.Y.Z/<graph>.{ttl,nt,rdf,jsonld}, Turtle canonical
# and the rest derived from it at deploy. Content negotiation over those
# four; browsers land on the release's index page, where per-IRI HTML
# anchors will go. Default (no Accept header) is Turtle.
#
# Generated by notebooks/80_generate_htaccess.ipynb in kerfors/cosmos-rdf
# and checked by scripts/htaccess_check.py against every IRI the
# deliverables carry. Edit there, not here.
#
# Status: draft, not a normative CDISC artifact. Offered for transfer to
# CDISC governance; transfer is a single PR against this .htaccess to
# change the redirect targets. See README.md.
